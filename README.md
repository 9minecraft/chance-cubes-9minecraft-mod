# Chance Cubes — Break Cubes for Loot or Chaos

Chance Cubes 9minecraft Mod brings a game of luck to your world with magic dice blocks. Breaking one of these cubes triggers a random event that can either help you or cause total chaos. You might get a chest full of valuable loot or suddenly find yourself trapped in a massive explosion. The mod adds special tools to help you guess what will happen before you break a block. Players can also build larger dice structures for even bigger payouts.

## What this build is

An unofficial rebuild of **TheTurkeyDev**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
